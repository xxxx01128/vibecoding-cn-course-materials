# 拿来说明 02：可复跑的「获取—翻译—校对—发布」管线

> 关键决策：把一次性劳动写成 4 个脚本 + 1 个编排器，路径全外置到配置。解决"翻完就废、换个源得重来"的问题。
> 结构：背景 → 原文/素材 → prompt → 产出 → 对比 → 复用方法。

---

## 一、要解决的问题

"翻译一套课程"如果只是手工下载、手工翻译、手工贴到文档里，那么：(1) 无法验证质量；(2) 换一门课要从零开始；(3) 别人无法复核或接手。Challenge 明确要求"管线可复跑、换源可复用"，所以必须工程化。

## 二、原文 / 素材（输入）

- 素材：`CS146S_offline.zip`（30 篇 HTML + 3 篇 PDF）+ `Vibe_Coding_Playbook.pdf` + `page_map.json`（URL→文件映射）。
- 环境起点：只有 Python 标准库，`beautifulsoup4`/`pypdf` 均未安装；`unzip` 命令在该 Shell 无输出。

## 三、Prompt（我用 AI 做的事）

**Prompt A — 设计提取脚本**

> 写一个从离线 HTML/PDF 抽取正文的脚本。要求：① 剥离导航/页脚/脚本噪音，保留标题层级、列表、代码块、链接；② 所有输入输出路径从 config/course.json 读取，便于换源；③ 生成 manifest 清单记录每篇来源、字数、状态；④ 幂等可重复运行；⑤ 缺依赖时给出友好安装提示。

**Prompt B — 一键编排**

> 写一个 run_all.py，把提取、分段、抽检、发布四步串成一条命令；支持 --with-todo 生成待译清单；每个脚本可单独运行；重复执行不产生副作用。

**Prompt C — 修 bug（真实踩坑）**

> 运行 01_extract.py 报 FileNotFoundError，输出路径变成了 Desktop\data\manifest.json 而不是资料包内。配置里 target.* 写的是 ../原文、../data/...。请分析根因并修复。

## 四、产出

一条命令跑完全流程：

```bash
python pipeline/run_all.py --with-todo
```

实际执行输出（摘录）：

```
============================================================
▶ 运行 01_extract.py
============================================================
[extract] 共 35 项 -> ...\原文
[extract] 有正文=30  占位=2  空=3
[extract] 正文总字符=606789
============================================================
▶ 运行 02_segment.py
============================================================
[segment] 26 个长文件共切成 79 段 -> data/segments/
============================================================
▶ 运行 03_qa_check.py
============================================================
[qa] 覆盖率 100.0% (30/30) PASS
```

**配置文件** `config/course.json` 把"源"（`source.offline_dir`/`zip`，可带 `../`）与"目标"（`target.*`，资料包内相对路径）分开，并加注释说明——这正是修完 `../` bug 后的沉淀。

## 五、对比

| 维度 | 手工一次性翻译 | 管线化（本方案） |
|---|---|---|
| 换一门课 | 全部重来 | 改 `course.json` + `glossary.json`，重跑 `run_all.py` |
| 质量验证 | 凭感觉、抽样看 | `03_qa_check.py` 逐篇出数字报告 |
| 覆盖统计 | 手数 | manifest 自动生成，分母口径明确 |
| 复跑一致性 | 每次不一样 | 幂等脚本，结果可复核 |
| 他人接手 | 需要口头交接 | README + 脚本即文档 |
| 修 bug 成本 | 无从追溯 | 报错→日志→修复→沉淀为注释 |

**修复 `/` bug 的对比**：v1 输出散落到桌面 → v2 路径外置并加注释，同类错误不再发生。

## 六、怎么拿来用（换源三步）

1. **换源**：编辑 `config/course.json`，把 `source.offline_dir`/`zip` 指向新素材，改 `course` 元信息。
2. **换术语**：编辑 `术语表/glossary.json`，放入新领域的术语。
3. **跑**：`pip install beautifulsoup4 pypdf` → `python pipeline/run_all.py --with-todo`，按待译清单完成翻译后再跑一次。

> **一句话**：把"我会做"变成"脚本会做"，价值不在省一次力，而在**让每一次都能被验证、被复现、被迁移**。
