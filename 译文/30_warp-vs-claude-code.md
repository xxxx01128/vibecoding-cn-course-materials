# Warp 与 Oz 入门 | Warp

> 来源: https://www.warp.dev/university/getting-started/warp-vs-claude-code

Warp 是一个智能体开发环境（Agentic Development Environment），它将现代终端与强大的智能体相结合，帮助你构建、测试、部署和调试代码。Warp 的 AI 由 Oz 驱动，Oz 是面向云端智能体的编排平台。

Warp 把现代终端与 Oz（面向云端智能体的编排平台）结合在一起

## Warp

Warp 是你工作的地方——一个快速、现代的终端，专为与智能体一起编码而打造。

核心能力：

- 智能体模式（Agent Modality）：在用于命令的简洁终端与用于多轮智能体工作流的专属对话视图之间切换。
- 现代终端用户体验（UX）：光标移动、基于块的导航、多行编辑、语法高亮和丰富的自动补全。用 Rust 构建，性能卓越。
- 代码编辑器：文件树、支持 LSP 的代码编辑器，以及交互式代码评审体验。
- 编码智能体集成：诸如语音输入和 @-选择等功能，可用于处理终端中的图像。兼容 Oz 或 Claude Code、Codex 等智能体。

深入了解 Warp 的核心功能

## Oz：面向云端智能体的编排平台

Oz 是驱动 Warp 所有智能功能的云端智能体编排平台。Oz 的设计目标是大规模协调智能体——理解你的代码库、自主执行任务，并适应你的工作流。Oz 在设计上是多模型的，让你可以灵活地为每项任务选择最合适的大语言模型（LLM）。

Oz 以两种模式运行：

### 本地智能体

直接在 Warp 应用中运行，提供实时、交互式的编码辅助。

- 跨你的代码库编写和重构代码
- 调试问题并修复错误
- 运行命令并解读结果
- 规划并执行多步骤任务

本地智能体让你保持掌控。你可以评审改动、在任务中途引导智能体，并在操作执行前进行批准。

→[开始使用本地智能体](https://docs.warp.dev/agent-platform/local-agents/overview)

### 云端智能体

Oz 云端智能体在 Warp 的基础设施（或你自己的基础设施）上后台运行，实现大规模自动化。

- 触发器：响应来自 Slack、Linear、GitHub 或自定义 webhook 的事件
- 计划任务：运行周期性任务，如依赖更新或死代码清理
- 并行性：跨代码仓库或任务并发运行多个智能体
- 可观测性：每一次运行都被追踪、可审计，并可与你的团队共享

云端智能体非常适合那些不需要你立即关注的工作，比如 PR 评审、issue 分流、日常维护以及由集成驱动的工作流。

→[了解云端智能体](https://docs.warp.dev/agent-platform/cloud-agents/overview)

## 它们如何协同工作

Warp 和 Oz 在本地与云端开发中提供统一的体验：

- 同一智能体，无处不在：无论你是在 Warp 中交互式工作，还是在云端运行智能体，你使用的都是同样的底层智能体能力。
- 无缝交接：在云端启动任务，当你想亲自掌控时，在 Warp 中本地接管，而不会丢失进度或上下文。
- 共享上下文：Warp Drive、规则和 MCP 服务器在本地与云端智能体中都可用，因此团队的知识与工具始终触手可及。
- 团队协作：共享智能体会话、评审智能体的操作，并引导正在运行的任务，无论任务是谁启动的。

## 多模型支持

Oz 在设计上就是多模型的。你可以从一组精选的顶级模型中 [选择你偏好的大语言模型（LLM）](https://docs.warp.dev/agent-platform/capabilities/model-choice)。

## 隐私与安全

Warp 符合 SOC 2 标准，并对所有签约的大语言模型（LLM）提供商执行零数据保留（Zero Data Retention）政策。任何客户 AI 数据都不会被保留、存储或用于训练。

Warp 的 AI 功能可以在「设置 > AI」中全局禁用。

→[阅读更多关于数据隐私的内容](https://www.warp.dev/privacy)
